## 🚀 Funcionalidades Técnicas
- **Consumo de API:** Uso de **Fetch API** para requisições assíncronas em tempo real.
- **Higienização de Inputs:** Tratamento de dados via **Regex (Expressões Regulares)** para garantir que apenas números sejam processados, prevenindo vulnerabilidades.
- **Tratamento de Erros:** Sistema de **Error Handling** amigável para CEPs inexistentes ou falhas de conexão.
- **Feedback Dinâmico:** Implementação de *loaders* (carregamento) e manipulação dinâmica do **DOM** para exibição dos resultados.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e acessível.
- **CSS3 Moderno:** Layout responsivo focado em dispositivos móveis.
- **JavaScript (ES6+):** Lógica assíncrona (Promises).
- **ViaCEP API:** Webservice de alta disponibilidade para dados de endereçamento.
